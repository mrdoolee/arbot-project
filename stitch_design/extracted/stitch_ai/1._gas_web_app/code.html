1
템플릿 사본 생성

제공된 [과학탐구 논증 템플릿 스프레드시트 사본 만들기] 링크를 클릭하여 내 드라이브에 복사합니다.

2
Apps Script 실행

구글 스프레드시트 상단 메뉴에서 [확장 프로그램] > [Apps Script]를 엽니다.

3
새 웹 앱 배포

우측 상단 [배포] > [새 배포]를 누르고, 액세스 권한을 '모든 사용자(Anyone)'로 지정해 배포합니다.

4
웹 앱 URL 등록

발급된 '웹 앱 URL'을 복사하여 위의 입력창에 붙여넣고 [URL 저장]을 누르면 연동이 완료됩니다.

Gemini API 키 및 고급 설정

소크라테스식 논증 보조 프롬프트 엔진 및 백업 인프라 자격 증명을 설정합니다.

메인 연동 외 별도 아카이브용 스프레드시트 파일 고유 ID

1
AI Studio 접속

Google AI Studio (aistudio.google.com)에 구글 계정으로 접속합니다.

2
키 생성 메뉴 선택

좌측 상단 네비게이션에서 [Get API key] 메뉴를 클릭한 뒤 [Create API key]를 누릅니다.

3
API 키 복사

생성된 긴 문자열의 API 키를 클립보드에 복사하여 상단 'Gemini API 키' 입력란에 붙여넣습니다.

4
활성화 확인

[저장하기]를 누르면 학생과의 실시간 문답을 이끌 소크라테스 발문 엔진이 즉시 활성화됩니다.

warning

주의: API 키는 외부나 학생에게 노출되지 않도록 교사용 콘솔에서만 안전하게 관리하세요. 브라우저 로컬 저장소 외의 원격 클라우드로 평문 전송되지 않습니다.
