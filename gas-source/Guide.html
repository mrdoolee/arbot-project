📖 아르봇(ARBOT) 사용 가이드

이 스프레드시트는 아르봇(ARBOT, ARgument chatBOT)의 데이터 창고예요. 학생 대화·설정이 모두 여기에 저장되고, 대부분의 설정은 웹 교사 콘솔에서 바꿔요.

처음 한 번만 하면 돼요

  1. 사본 만들기 — 받은 스프레드시트를 파일 → 사본 만들기로 내 드라이브에 복사해요. Apps Script 코드가 함께 복사돼요.
  2. Gemini API 키 넣기 — 환경설정 탭 B1에 키를 붙여넣어요(aistudio.google.com에서 발급). 교사 콘솔에서 넣어도 돼요.
  3. 교사 비밀번호 정하기 — 상단 메뉴 🗣️ 아르봇(ARBOT) → 🔐 교사 비밀번호 설정에서 8자 이상으로 두 번 입력해요. 처음 누르면 "권한 승인" 창이 떠요 → 계속 → 계정 선택 → 고급 → (안전하지 않은 페이지로) 이동 → 허용을 눌러 주세요. 이때 수업 입장 코드도 자동으로 만들어져요.
  4. 웹 앱으로 배포하기 — 확장 프로그램 → Apps Script를 열고 우측 상단 배포 → 새 배포, 유형 웹 앱, 액세스 권한 "모든 사용자"로 배포해요. 나오는 주소(…/exec)를 복사해 두세요.
  5. 교사 콘솔에 연결하기 — 아르봇 교사 콘솔(웹 페이지)을 열고 1. GAS 연동에 주소를 붙여넣어 연결 테스트 → URL 저장, 교사 비밀번호를 입력해요.
  6. 수업 준비하기 — 콘솔에서 학급·모둠·주제·페르소나를 정하고, 4. 학생 배부 링크 & QR에서 링크와 수업 입장 코드를 학생에게 나눠 줘요.

수업이 끝나면 콘솔의 5. 대화 결과 확인 & 분석에서 대화를 AI가 논증 요소별로 분석한 결과를 볼 수 있어요. 자세한 사용법은 콘솔 왼쪽 아래 사용 가이드 버튼에 있어요.

지우면 그 대화는 분석할 수 없어요.

시트에 보이지 않는 것 — 교사 비밀번호(암호화해서)와 수업 입장 코드는 시트 칸이 아니라 스크립트 안에 저장돼요. 그래서 시트를 공유해도 비밀번호가 보이지 않아요.

시트에서 직접 고친 설정은 최대 5분 뒤에 학생 화면에 반영돼요. 콘솔에서 저장하면 바로 반영돼요.

상단 메뉴 🗣️ 아르봇(ARBOT)

  • 📖 사용 가이드 — 지금 보고 있는 창이에요.
  • ℹ️ 정보 — 제작자와 이용 조건, 문의처를 보여 줘요.
  • 🔐 교사 비밀번호 설정 — 교사 콘솔 비밀번호를 정하거나 다시 정해요(8자 이상). 이 시트를 열 수 있는 사람만 할 수 있어서, 잊어버렸을 때도 여기서 새로 정하면 돼요. 정하기 전에는 교사 콘솔의 설정·분석 메뉴가 열리지 않아요.
  • 🔑 수업 입장 코드 보기 — 학생이 대화방에 들어갈 때 입력하는 코드를 보여 줘요(없으면 만들어요). 새 코드로 바꾸는 건 콘솔 4. 학생 배부 링크 & QR에서 해요.
  • 🔄 주제 세부설정 맞추기 — 주제 목록(기본설정 B13)에 있는 주제마다 주제 세부설정 탭에 줄을 만들어요. 교사 콘솔에서 주제 목록을 저장하면 자동으로 되니, 시트에서 목록 칸을 직접 고쳤을 때 눌러요. 값이 든 줄은 지우지 않아요.
  • 🩺 시트 구조 점검 — 탭이 빠졌거나 칸이 어긋났는지 찾아서 알려 줘요. 읽기만 하고 아무것도 바꾸지 않아요. 시트를 직접 고친 뒤에 이상하면 먼저 눌러 보세요.
  • ⚠️ 설정·기록 초기화… — 학급·모둠·주제·금지어, 세부설정 탭, 탐구자료, 채팅기록 전체를 처음 상태로 되돌려요. 되돌릴 수 없고 확인창이 두 번 나와요. 환경설정(키)·API키·교사 비밀번호는 그대로 남아요.

꼭 지켜 주세요

  • 탭 이름, 1행 머리글, 열 순서를 바꾸지 마세요. 코드가 이름과 위치로 찾아서, 바뀌면 학생 화면이 멈출 수 있어요.
  • 기본설정 탭은 행을 끼우거나 지우지 마세요. B10 ~ B13 칸이 위치로 고정돼 있어요. 안 쓰는 행은 숨기기만 하세요.
  • "기본" 줄(페르소나·루브릭 2행)과 "(기본)" 줄(주제 세부설정 2행)은 지우지 마세요. 다른 줄이 비워 둔 칸을 따라갈 기준이에요.
  • 이 시트를 다른 선생님께 사본으로 드리기 전에 환경설정 B1(내 API 키)과 API키 탭, 채팅기록을 지워 주세요. 사본에 그대로 따라가요. (⚠️ 설정·기록 초기화…는 키를 지우지 않아요.)
  • 학생 대화는 선생님 시트에만 저장되지만, 답을 만들기 위해 대화 내용이 AI 서비스(구글 Gemini)로 전달돼요. 학생에게 개인정보를 쓰지 않도록 안내해 주세요.

이럴 땐

  • 메뉴가 보이지 않아요 — 시트를 새로고침(F5)하세요. 처음에는 몇 초 걸릴 수 있어요.
  • "권한이 필요해요" 창이 떠요 — 위 3번 단계처럼 계정을 고르고 고급 → 이동 → 허용을 눌러 주세요.
  • 콘솔이 "GAS가 옛 버전"이라고 해요 — Apps Script 편집기에서 배포 → 배포 관리 → 연필 → 새 버전으로 다시 배포하세요.
  • 비밀번호를 잊었어요 — 메뉴 🔐 교사 비밀번호 설정에서 새로 정하면 돼요.
  • 학생이 "AI를 사용할 수 없어요"라고 해요 — API 키의 사용 한도가 끝났거나 오류예요. 콘솔 메뉴 1에서 키를 추가하거나 잠시 뒤 다시 해 보세요.
  • 탭을 지웠거나 칸을 옮긴 것 같아요 — 🩺 시트 구조 점검을 눌러 어디가 어긋났는지 확인하세요.

문의가 있으면 메뉴 ℹ️ 정보의 연락처로 알려 주세요. 간단한 질문 위주로 답변드리며, 답변이 늦어질 수 있습니다.
