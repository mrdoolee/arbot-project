먼저 교사 비밀번호를 정해 주세요

처음 한 번만 하면 돼요. 비밀번호를 정하기 전에는 이 콘솔의 다른 메뉴가 열리지 않아요.

key
초기 비밀번호는 "12345678"입니다.아래에 초기 비밀번호와 새로 쓸 비밀번호(8자 이상)를 넣으면 바로 시작할 수 있어요.
새 비밀번호를 정하면 초기 비밀번호는 더 이상 쓸 수 없어요. 초기 비밀번호로는 새 비밀번호를 정하는 것만 할 수 있어요.
shield_lock
왜 먼저 정하나요?학생 접속 링크에는 이 시트의 웹 앱 주소가 들어 있어요. 비밀번호가 없으면 그 주소만으로 API 키나 학생 대화에 접근할 수 있어서, 비밀번호를 정해야 설정·분석 기능이 열리도록 했어요.

또는 스프레드시트 메뉴에서 정할 수도 있어요.

1
스프레드시트 열기연결한 스프레드시트 탭으로 이동해요. (연결 테스트 후 [스프레드시트 접속] 버튼으로도 열 수 있어요)
2
메뉴에서 비밀번호 설정상단 메뉴 🗣️ 아르봇(ARBOT) → 🔐 교사 비밀번호 설정을 눌러 8자 이상으로 두 번 입력해요. 메뉴가 안 보이면 시트를 새로고침(F5)하세요.
3
여기서 다시 확인아래 [연결 다시 확인]을 누르면 비밀번호 입력창이 나와요.

초기 비밀번호(12345678)는 처음 한 번 새 비밀번호를 정하는 데만 쓰여요.

하루·분당 요청 한도는 Google 프로젝트와 모델마다 달라요.
Google AI Studio(aistudio.google.com)의 사용량 · 요청 한도 화면에서 쓰는 모델의 RPD(하루 요청 수)를 확인해 주세요.
모델 칸을 비워 두면 한도가 넉넉한 Flash-Lite가 자동으로 골라져요. 한도는 키가 아니라 프로젝트 단위로 세므로, 대비용 추가 키는 다른 Google 프로젝트에서 만들어야 도움이 돼요. 무료 한도는 예고 없이 바뀔 수 있어요.
위의 기본 키가 먼저 쓰이고, 크레딧·한도가 다 떨어지거나 키에 문제가 생기면 추가 키가 위에서부터 차례로 쓰여요. 한도가 소진된 키는 잠시 쉬었다가(몇 시간) 저절로 다시 시도하고, 충전했다면 쉬는 중 해제를 눌러 바로 다시 쓸 수 있어요.
모든 키가 소진되면 학생에게는 "지금은 AI를 사용할 수 없어요"가 보여요. 추가 키도 스프레드시트의 API키 탭에 평문으로 저장되니 시트를 공유하지 마세요.

개인정보·보안 안내

수업을 시작하기 전에 한 번 확인해 주세요.

  • 스프레드시트는 공유하지 마세요. 학생 대화 원문과 API 키가 들어 있어요. "링크가 있는 모든 사용자"로 공유하면 누구나 볼 수 있어요.
  • 학생 링크·QR은 우리 반에게만 전하세요. 학생이 들어올 때는 수업 입장 코드도 필요해요. 링크가 반 밖으로 퍼졌다면 학생 배부 메뉴에서 새 코드를 만들면 이전 코드는 바로 쓸 수 없게 돼요.
  • 학생에게 이름·전화번호·주소를 쓰지 않게 안내하세요. 쓴 내용은 그대로 시트에 기록돼요.
  • Gemini 무료 키는 입력한 내용이 구글의 서비스 개선에 쓰일 수 있다는 약관이 있어요(약관은 바뀔 수 있으니 최신 내용을 확인해 주세요). 학교 방침에 따라 학생·학부모 안내나 유료 키 사용을 검토하세요.
  • 학기가 끝나면 대화 기록을 정리하세요. 필요한 분석은 보고서로 내려받고, 시트의 채팅기록을 따로 백업한 뒤 비우면 돼요.

menu_book아르봇(ARBOT) 사용 가이드

아르봇(ARBOT)은 ARgument chatBOT의 줄임말이에요. 학생이 AI 튜터와 대화하며 주장 → 근거 → 추론 순서로 논증하는 연습을 하고, 선생님은 그 대화를 AI가 요소별로 분석한 결과로 확인하는 수업 도구예요.

1
스프레드시트 준비사본 만들기 → 교사 비밀번호 정하기 → 웹 앱으로 배포
2

3

4
학생에게 배부링크·QR과 수업 입장 코드 나눠 주기 (메뉴 4)
5
수업 진행학생이 코드를 넣고 입장해 AI 튜터와 대화해요
6
결과 확인대화를 불러와 논증 분석 보기 (메뉴 5)
hub메뉴 1 · GAS 연동 — 스프레드시트와 콘솔 잇기expand_more
  • 스프레드시트를 파일 → 사본 만들기로 복사하고 웹 앱으로 배포한 뒤, 이 콘솔에 연결하면 비밀번호를 정하는 칸이 나와요. 초기 비밀번호는 "12345678"입니다. 초기 비밀번호와 새 비밀번호(8자 이상)를 넣으면 바로 시작할 수 있어요(상단 메뉴 🗣️ 아르봇(ARBOT) → 🔐 교사 비밀번호 설정에서 정해도 돼요). 정하기 전에는 다른 메뉴가 잠겨 있어요.
  • 확장 프로그램 → Apps Script → 배포 → 새 배포에서 유형 웹 앱, 액세스 권한 "모든 사용자"로 배포하고 발급된 주소(…/exec)를 복사해요.
  • 콘솔에 주소를 붙여넣고 연결 테스트 → URL 저장, 이어서 교사 비밀번호를 입력해요. 연결되면 스프레드시트 접속 버튼으로 시트를 바로 열 수 있어요.
  • Gemini API 키(aistudio.google.com에서 발급)를 입력해 저장해요. 저장된 키는 일부만 보이고, 그대로 두면 바뀌지 않아요. 추가 키를 넣어 두면 한 키의 한도가 끝나거나 오류일 때 다음 키로 자동 전환돼요(쉬는 중 해제로 다시 쓰기).
  • AI 모델은 비워 두면 자동으로 골라요. 바꾸고 싶을 때만 모델 목록 불러오기 · 모델 테스트를 쓰세요.
  • 설정 저장 버튼은 불러오기가 끝난 뒤에만 눌려요. 빈 화면으로 시트 설정을 덮어쓰는 사고를 막기 위한 장치예요.
tune메뉴 2 · 기본 설정 — 학급, 캐릭터, 페르소나, 루브릭expand_more
  • ① 학급 · 모둠 · 금지어 — 쉼표(,)로 구분해 입력해요. 학생은 여기 있는 학급·모둠만 고를 수 있고, 금지어를 3번 쓰면 그날은 대화가 차단돼요.
  • ② 캐릭터 · 인사말 · 페르소나 — 위쪽에서 편집할 페르소나(기본 / 템플릿 / 내가 만든 것)를 고르면, 학생 화면에 보일 캐릭터·첫 인사말(미리보기 제공)과 AI의 역할·행동 지침·절대 제한·예외 대처·추가 참고를 고칠 수 있어요. 캐릭터는 대화 방식(템플릿)마다 한 명씩 짝이 있어서, 대화 방식을 바꾸면 직접 고르지 않은 캐릭터·인사말도 함께 바뀌어요. 비워 둔 칸은 기본 페르소나를 따라요.
  • 대화 방식(템플릿) 5가지 — 소크라테스 발문형 · CER 코치형 · 고급 논쟁형 · 찬반 토론형 · 탐구 도우미(실험 질문에 답하는 용도, 평가 없음). 템플릿 원본은 고쳐지지 않아요. 고치면 "이름 (수정)"이라는 새 줄로 따로 저장돼요.
  • ③ 평가 루브릭 — 분석할 때 AI가 따르는 평가 기준이에요. 같은 이름의 페르소나와 짝을 이뤄 함께 열리고, 탐구 도우미에는 루브릭이 없어요.
topic메뉴 3 · 주제 설정 — 주제 목록, 주제 연결, 탐구 자료expand_more
  • ① 탐구 주제 목록 — 학생이 고를 주제를 정하고 저장해요. 저장하면 스프레드시트의 주제 세부설정 탭에도 그 주제의 줄이 자동으로 만들어져요(시트에서 목록을 직접 고쳤다면 시트 메뉴 🔄 주제 세부설정 맞추기).
  • ② 주제 연결 — 주제마다 쓸 페르소나·루브릭·제한 시간(분)·AI가 기억할 대화 수를 정해요. 비워 둔 칸은 (기본) 줄을 따르고, 줄마다 저장하거나 기본으로 되돌릴 수 있어요. 시트의 주제 세부설정 탭에서 그 줄의 칸을 직접 채워도 같은 효과예요.
  • ③ 탐구 자료 — 탐구 도우미에 연결한 주제는 실험 과정·준비물·유의사항·교사용 메모가 있어야 학생이 열 수 있어요(없으면 "준비 중"으로 보여요). 논증 주제에도 넣어 두면 분석 때 참고 자료로 쓸 수 있어요.
qr_code_2메뉴 4 · 학생 배부 링크 & QRexpand_more
  • 학생용 링크를 링크 복사로 학급 메신저에 보내거나 QR로 보여 줘요. 링크 안에 이 시트의 웹 앱 주소가 들어 있으니 선생님이 직접 나눠 주세요.
  • 수업 입장 코드 — 학생은 링크를 열고 이 코드를 입력해야 들어올 수 있어요. 코드 복사 · 새 코드 만들기 · 직접 정하기(영문 대문자·숫자 6~12자)를 쓸 수 있어요.
  • 링크가 반 밖으로 퍼졌거나 새 수업을 시작할 때 새 코드를 만들면 이전 코드는 바로 쓸 수 없어요. 수업 중에 바꾸면 이미 들어온 학생도 다음 전송 때 다시 입장해야 해요.
  • 교실 TV 전체화면(QR과 코드, Esc로 닫기)과 A4 배부용 QR 인쇄를 쓸 수 있어요.
  • "이 컴퓨터에서만 열리는 주소" 경고가 보이면 콘솔을 웹에 배포된 주소로 열어야 학생 기기에서 접속돼요.
query_stats메뉴 5 · 대화 결과 확인 & 분석expand_more
  • 학급 → 탐구 주제 → 모둠 → 날짜 순서로 단추를 눌러 골라요. 앞 단계를 고르기 전에는 뒤 단계 단추가 꺼져 있고, 대화 기록이 없는 학급·주제·모둠은 기록 없음으로 표시돼 누를 수 없어요. 같은 주제를 여러 날 나눠 했다면 날짜마다 단추가 생겨 그날의 대화만 분석할 수 있고(모든 날짜 함께도 고를 수 있어요), 하루만 했다면 날짜는 저절로 골라져요. 모두 고르면 대화 불러오기 및 분석 실행 버튼이 켜져요. 평가 제외(탐구 도우미 등) 대화는 분석은 안 되지만 단추를 누른 뒤 대화 기록 보기로 기록을 확인할 수 있어요(평가 대상 대화도 평가 없이 기록만 볼 수 있어요).
  • 이 메뉴에 들어올 때마다 목록과 기록을 새로 읽어요. 수업 중에 새 대화가 생겼다면 목록·기록 새로고침을 눌러 주세요. 탐구 도우미 대화처럼 평가하지 않는 대화만 있는 곳은 평가 제외로 표시돼요.
  • 결과에는 종합 논증 수준, 대화에 나타난 논증 요소, 대화 흐름 차트(점을 누르면 그때의 발언과 판정), 담화 맥락별 평가, 교사용 지도 가이드(진단 · 강점 · 지도 방향 · 추천 발문), 발언별 판정 표(판정 칩으로 걸러 보기)가 나와요. HTML 보고서 · 인쇄 · CSV로 내보낼 수 있어요.
  • 논증 수준은 논증의 구조를 보는 값이라 과학적으로 맞는지는 판단하지 않아요. 탐구 자료를 반영해도 코멘트에만 쓰여요.
  • 같은 대화를 다시 분석하면 판정이 조금 달라질 수 있어요(AI의 특성). 결과는 수업 참고 자료로 봐 주세요.
  • 탐구 도우미로 나눈 대화는 분석에서 빠져요. 다른 루브릭으로 나눈 대화가 있으면 그 루브릭으로 분석하는 버튼이 함께 보여요.
school학생 화면 안내 (학생에게 알려 줄 내용)expand_more
  • 링크(또는 QR)로 들어와 수업 입장 코드를 입력하고, 학급 · 모둠 · 탐구 주제를 고른 뒤 탐구 대화방 입장하기를 눌러요.
  • 대화방에는 AI 튜터와 논증 가이드(대화 방식에 따라 주장 → 근거 → 추론 등 단계가 달라져요)가 고정돼 있고, 아래 입력창에 내 생각을 써서 보내요. 막힐 때는 입력창 위의 시작 문장 버튼을 써요.
  • AI는 정답을 알려 주는 대신 질문으로 생각을 키워 줘요. 이름·전화번호 같은 개인정보는 쓰지 않아요.
  • 주제마다 정한 제한 시간이 있으면 위쪽에 타이머가 보여요. 시간이 끝나면 오늘의 탐구 요약과 함께, 학생이 나눈 대화를 돌아본 100자 이내의 오늘의 피드백이 채팅창에 올라와요(이 피드백은 시트에 기록되지 않아요).
  • 금지어를 쓰면 경고가 쌓이고 3번이면 그날 대화가 차단돼요. 주제와 상관없는 이야기를 계속하면 AI가 그 모둠을 10분 동안 차단해요.
  • 접속이 안 될 때 — ① 학교 Wi-Fi 또는 LTE/5G에 연결돼 있는지 확인해요. ② 별도 앱 없이 스마트폰 기본 카메라로 QR을 비추면 웹 배너가 떠요. ③ 인식이 안 되면 Chrome 등에서 링크를 직접 열어요(링크 복사 버튼으로 학급 메신저에 보낼 수 있어요).
  • 사이드바의 학생 화면 열어보기로 미리 체험할 수 있어요. 연습 대화도 시트에 기록돼요.
shield_lock보안과 개인정보expand_more
  • 교사 콘솔은 교사 비밀번호로 잠겨 있어요. 비밀번호는 시트 칸이 아니라 스크립트에 암호화되어 저장되고, 잊으면 시트 메뉴 🔐 교사 비밀번호 설정에서 다시 정하거나, ♻️ 교사 비밀번호 초기화로 처음 상태로 되돌려요(시트를 열 수 있는 사람만 가능). 초기 비밀번호(12345678)는 아직 비밀번호가 없을 때 새 비밀번호를 정하는 데만 쓰이고, 정한 뒤에는 쓸 수 없어요.
  • 학생은 수업 입장 코드가 있어야 들어올 수 있어요. 코드는 4번 메뉴나 시트 메뉴 🔑 수업 입장 코드 보기에서 확인해요.
  • 학생 대화와 분석 결과는 선생님의 구글 스프레드시트에만 저장돼요. 다만 질문에 답하기 위해 대화 내용이 AI 서비스(구글 Gemini)로 전달돼요.
  • API 키는 화면에 전체가 다시 보이지 않아요. 링크나 QR이 학급 밖으로 퍼졌다면 새 입장 코드를 만들어 주세요.
  • 스프레드시트 공유 권한 — 웹 앱은 선생님 계정으로 시트에 기록해요(백업 시트도 같아요). 그래서 시트를 공유하지 않아도 학생 대화가 쌓여요. 시트의 [공유] → 일반 액세스는 "제한됨"으로 두세요. "링크가 있는 모든 사용자"로 열면 링크를 아는 사람에게 환경설정 B1의 API 키와 학생 대화가 그대로 보여요.
  • 다른 사람을 추가할 때 — 뷰어도 API 키와 학생 대화를 볼 수 있고, 편집자는 설정을 바꾸고 시트 메뉴(♻️ 교사 비밀번호 초기화, 🔑 수업 입장 코드 보기, ⚠️ 설정·기록 초기화)를 실행하고 Apps Script 코드도 고칠 수 있어요. 함께 수업하는 믿을 수 있는 선생님만 편집자로 추가하세요. 교사 비밀번호는 암호화돼 있어 편집자도 원래 값은 볼 수 없어요.
  • 다른 선생님께 나눠 줄 때 — 공유 대신 사본 만들기로 드리고, 그 전에 환경설정 B1의 키, API키 탭, 채팅기록을 비워 주세요. 사본에 그대로 따라가요.
help자주 겪는 문제expand_more
  • 연결 테스트가 실패해요 — 주소가 https://script.google.com/…/exec 형태인지, 웹 앱 액세스 권한이 "모든 사용자"인지 확인해요. 방금 배포했다면 5~10초 뒤에 다시 눌러 보세요.
  • "GAS가 옛 버전이에요" 카드가 떠요 — 시트의 Apps Script가 콘솔보다 오래됐다는 뜻이에요. 최신 코드로 배포 → 배포 관리 → 새 버전으로 다시 배포하세요.
  • 사이드바 메뉴가 회색으로 잠겨 있어요 — 연결과 비밀번호 입력이 끝나야 열려요.
  • 저장 버튼이 눌리지 않아요 — 같은 화면의 불러오기를 먼저 눌러 주세요.
  • 학생 화면에 "코드가 바뀌었어요"가 떠요 — 새 수업 입장 코드를 알려 주세요.
  • "지금은 AI를 사용할 수 없어요"가 떠요 — API 키의 사용 한도가 끝났거나 오류예요. 키를 추가하거나 잠시 뒤 다시 해 보세요(메뉴 1에서 키 상태 확인).
  • 시트가 이상해요(탭을 지웠거나 칸을 옮겼을 때) — 시트 메뉴 🩺 시트 구조 점검이 어긋난 곳을 찾아 알려 줘요(읽기만 하고 아무것도 바꾸지 않아요). 시트 구조는 시트 메뉴 📖 사용 가이드에서 볼 수 있어요.
